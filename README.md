📘 BU Student Navigator Bot
An unofficial but super helpful guide for Boston University students, parents, international students, and graduate students.


🚀 Overview
BU Student Navigator Bot is a custom AI assistant built using OpenAI Custom GPTs.
Its goal is to help current and future BU students navigate academic life, campus logistics, housing, mental health resources, and more — all while linking to official BU sources.

This project showcases:
Custom GPT design
Prompt engineering
User experience planning
Resource organization
Educational assistant design
Practical AI deployment for real student needs
This GPT is unofficial and does not represent Boston University.

🎯 Features

✅ Academic Support
Course descriptions (CS111, CS112, CS131, etc.)
Study tips and BU-specific guidance
How to register, add/drop, or find prerequisites

✅ Campus Navigation
Building locations (CAS, ENG, CDS, PSY, SHA, etc.)
BUS route guidance
Green Line (B-branch) explanations
Walking shortcuts & time estimates

✅ Student Life Information
Dining halls & ratings
Study spaces
Clubs & activities
Fitness centers (FitRec)

✅ Administrative Help
Housing selection explanation
Financial aid overview
Leave of absence basics
International student resources (ISSO)

✅ Always Includes Official Links
Every answer includes links to:
BU Registrar
ISSO
Housing
Dining
Course search
FitRec
…and more.

🧠 How It Works
The bot uses a detailed Instruction set that defines:
Tone (friendly, clear, unofficial)
Scope (all BU-related life topics)
Audience (students, parents, international students, grads)
Safety rules (no medical/legal advice)
It also uses:
Web Search capability for live BU information
Carefully crafted conversation starters to guide new users

🔧 Tech Stack
OpenAI Custom GPT
Web Browsing enabled
Image & Code tools disabled
Prompt engineering
Chat-based UX design
No backend or database required — fully built and hosted via OpenAI’s GPT Builder.
